# Pong Game 
This is a simple pong which is built upon kivy module. 
Which is a fine module for making app which is cross-site.

## How to play?
It is a simple game, maybe remebered by every kids from 20's who has access to that arcade generations.
To play this project/game simply just clone the project, checkout the branch and then run the main.py
*This is project is backed by uv package manager, so remember to use with uv for great experience.*
*Rather just install the packages from the **pyproject.toml** as no requirements.txt file available.*
***I strongly suggest use the uv and get out of the classic pip guy.***
